# Security reporting

Report suspected vulnerabilities privately to [support@enrichley.io](mailto:support@enrichley.io), the contact listed on our [support page](https://docs.enrichley.io/support). Use a subject such as “Security report: Enrichley MCP plugin” and include affected versions and a safe description of how to reproduce the issue.

Do not include credentials, signed quote tokens, customer data, or sensitive logs in public issues or pull requests. Start with a redacted description by email; coordinate any sensitive supporting material privately.
